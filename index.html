Project 01
Career Pilot AI

An AI-powered career platform that helps job seekers analyze resumes, match skills with opportunities, track applications, and improve career readiness.

Problem: I noticed that many job seekers struggle with improving their CVs, understanding missing skills, and keeping track of multiple job applications. I wanted to build a platform that could make the job search process more organised and data-driven.

Solution: Career Pilot AI is an AI-powered career platform that helps users analyse resumes, compare skills against job requirements, track applications, and receive AI-based career recommendations.

Features
  • AI resume analysis with ATS-style scoring
  • CV-to-job matching and skill gap identification
  • Job application tracking dashboard
  • AI career assistant for guidance and recommendations

Technical Highlights: Built with Django REST Framework, PostgreSQL, JavaScript, JWT authentication, document processing, and Groq AI integration for intelligent resume and job analysis.

Technical Challenges & Solutions
  • Challenge: Integrating AI Responses Into My Application
    One of the biggest challenges was making sure AI-generated responses could be used reliably by the frontend dashboard. AI responses are not always returned in the same format.

    Solution: I improved my prompt design, structured the expected AI output, and added validation to make sure the application could process the responses correctly.
  • Challenge: Building Secure User Authentication
    Protecting user information and making sure only authorised users could access their data was an important part of the application.

    Solution: I implemented JWT authentication using access and refresh tokens to secure API endpoints and manage user sessions.
  • Challenge: Extracting Information From CV Documents
    Reading information from uploaded resumes was challenging because different CV formats contain different structures.

    Solution: I researched document processing techniques and implemented PDF and DOCX extraction using Python libraries to convert uploaded files into readable text for AI analysis.
  • Challenge: Designing the Application Database
    The system needed to manage users, profiles, applications, and application tracking events while keeping the data organised.

    Solution: I designed Django models and relationships using the ORM, which helped me understand how to structure data for a larger full-stack application.
  • Challenge: Deploying a Full AI Application
    Deploying an application with authentication, databases, static files, and external APIs required additional testing.

    Solution: I configured environment variables, PostgreSQL, Gunicorn, and Railway deployment settings to successfully run the application in production.

Project 04
FaceSight AI

An AI-powered facial analysis application that uses computer vision for real-time face detection, emotion analysis, and facial attribute estimation directly in the browser.

Problem: I wanted to explore how AI could be used in a practical web application. Many computer vision tools require users to install extra software or use complex setups, so I wanted to create a simpler browser-based experience.

Solution: FaceSight AI is a browser-based facial analysis application that uses the user's webcam to detect faces, analyse emotions, and estimate facial attributes without requiring additional software installation.

Features
  • Real-time face detection using a webcam
  • Emotion recognition and facial analysis
  • Age and gender estimation
  • AI processing directly in the browser using face-api.js

Technical Highlights: Built with Django and JavaScript, integrating face-api.js for browser-based AI processing, webcam access, machine learning models, and deployed using Gunicorn on Railway.

Technical Challenges & Solutions
  • Challenge: Running AI Models in the Browser
    One of the biggest challenges was understanding how to run machine learning models efficiently without sending all the processing to the backend.

    Solution: I researched browser-based AI tools and used face-api.js to run the models directly in the user's browser, reducing server workload and improving response time.
  • Challenge: Connecting the Webcam with the Application
    Accessing the user's camera and processing live video was challenging because browser permissions and video streams needed to be handled correctly.

    Solution: I used JavaScript browser media APIs to request webcam access, capture video input, and connect the stream with the AI detection process.
  • Challenge: Loading AI Models Correctly
    The application needed to make sure all required AI models were loaded before starting face detection.

    Solution: I created a model loading process that checks when the AI files are ready before allowing detection to begin.
  • Challenge: Improving Real-Time Performance
    Running face detection continuously can affect browser performance, especially on lower-powered devices.

    Solution: I adjusted the detection process and reduced unnecessary processing to create a smoother user experience while maintaining accurate results.
